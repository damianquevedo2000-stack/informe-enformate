# informe-enformate

Informe web de la empresa: ventas, costos y gastos, retiros.

- Estetica: dark glassmorphism (violeta / ambar / menta / rosa). Tipografias Sora, Inter y JetBrains Mono.
- Graficos: Chart.js 4 via CDN.
- Datos: js/data.js es la unica fuente de cifras, generada desde el Excel auditado.
- Publicacion: Netlify conectado a este repositorio (sin build, publish = raiz).
